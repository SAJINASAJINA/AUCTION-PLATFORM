# Prime Bid - Online Auction Platform

A full-stack MERN online auction platform that allows users to participate in auctions, place bids, manage auction items, view leaderboards, and provides administrative management features.

## Features

- User registration and login
- JWT-based authentication
- Role-based access control
- Create and manage auctions
- Bidding system
- Auction start and end time management
- Bid management
- Auction leaderboard
- My Auctions page
- Commission management
- Payment proof management
- Super Admin dashboard
- Cloudinary image upload
- Email functionality
- Responsive React frontend

## Tech Stack

### Frontend

- React
- Vite
- React Router
- Redux
- Tailwind CSS
- Axios

### Backend

- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- bcrypt
- Cloudinary
- Nodemailer
